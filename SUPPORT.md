# Support

This repository is a community reference implementation and does not provide an
Azure service-level agreement.

For help:

1. Read the deployment, operations, security, testing, and
   [`troubleshooting`](docs/troubleshooting.md) documentation.
2. Search existing GitHub issues.
3. Open a GitHub Discussion for usage questions.
4. Open an issue for a reproducible defect using the supplied issue template.

For Azure subscription, quota, regional availability, or service incidents, use
your normal Microsoft Azure support channel.

Do not post credentials, tenant details, customer data, or internal network
information in public discussions or issues.
